# WorkMesh AI — Product Vision

## 1. Long-Term Product Vision
WorkMesh AI is designed to be an AI-powered global remote work ecosystem combining core aspects of:
- **Professional Networking**: LinkedIn-style profiles, connections, and professional feeds.
- **Freelance & Worker Marketplace**: Upwork-style project listing, proposals, and worker profiles.
- **Uber-Style Task Dispatch**: AI-assisted, direct allocation and matching of granular tasks to verified remote workers.
- **AI Project Delivery**: Natural language project planning, milestone breakdown, automated risk detection, and quality monitoring.
- **Company Recruiting & Hiring**: Automated resume parsing, candidate ranking, multi-factor explainable matching, and talent pipelines.

## 2. Target Personas & Core Marketplace
- **Engineers / Freelancers / Remote Workers**: Discover jobs, manage AI-enhanced profiles, accept dispatched tasks, work on milestone projects, and network professionally.
- **Companies / Clients / HR / Recruiters**: Create hiring requirements, post jobs, run natural language AI project breakdown, discover and invite talent, manage application pipelines.

## 3. Incremental Core Pillars (MVP to Enterprise)
1. **Identity & Auth**: Multi-role support (ENGINEER, COMPANY, ADMIN).
2. **Engineer Profiles**: Resume upload, AI skill extraction, completeness score, portfolio/links.
3. **Company Profiles**: Organization details, Tech stack, hiring status, verification.
4. **Remote Jobs Marketplace**: Aggregated multi-source remote jobs (RemoteOK, Remotive, Arbeitnow, USAJobs, The Muse) with deduplication & search.
5. **Job Discovery**: Keyword, skill, location, timezone, and salary filtering.
6. **Explainable AI Matching Engine**: Multi-factor scoring (skills, experience, role, timezone, compensation, remote region).
7. **Professional Networking**: Connection requests, network graph, professional posts/feed.
8. **Real-time Messaging**: WebSocket-based client/engineer and peer communication.
9. **Company Hiring Marketplace**: Application pipelines, candidate discovery, invitations.
10. **Projects & Milestone Management**: Milestones, tasks, subtasks, assignments, progress.
11. **AI Project Planning & Manager**: Structured project generation, daily summaries, risk detection.
12. **Platform Admin Console**: Platform metrics, source sync health, user/job moderation.

## 4. Strategic Execution Principle
- **Existing repository = foundation.**
- **AI agents = incremental engineering team.**
- **Each prompt = one controlled work package.**
- **No agent is allowed to rebuild the application from scratch.**
