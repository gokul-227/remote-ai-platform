# Diagram icons

- `*.svg` — brand marks from [Simple Icons](https://simpleicons.org) (CC0), in each brand's colour
  (black marks drawn in slate so they read on white).
- `concepts/*.svg` — [Lucide](https://lucide.dev) icons (ISC, see `concepts/LICENSE`), the same set the
  web app uses, for features and generic concepts.

Vendored (not fetched at build time) so diagrams render identically offline and in CI.
